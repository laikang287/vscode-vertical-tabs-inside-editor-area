## [1.0.0] - 2026-07-23

<mark>대규모 버전 업데이트입니다. 변경 사항이 매우 많으므로 버그가 발생하면 버전 0.2.1로 되돌리는 것을 고려하세요.</mark>

### 주요 기능

- <mark>세로 탭의 컨텍스트 메뉴에 VS Code 가로 탭의 모든 버튼을 표시할 수 있습니다. VS Code 기본 버튼과 타사 확장에서 제공하는 버튼도 포함됩니다.</mark>
- 인터페이스 스타일을 VS Code 테마에 더 가깝게 업데이트했습니다.
- 작업 세트를 저장하고 불러올 수 있습니다.
- 세로 탭을 왼쪽 또는 오른쪽으로 전환할 수 있습니다.
- 검색 기능을 강화했습니다.
- `verticalTabs.relativePathDisplay` 설정을 추가했습니다. 예를 들어 이름이 같은 파일에만 상위 디렉터리 이름을 표시하는 등 탭에 경로를 표시할 조건을 지정할 수 있습니다.
- 탭 전환과 이동 등을 지원하는 여러 개의 설정 가능한 바로 가기 키를 추가했습니다.
    - 자세한 내용은 키보드 바로 가기 설명을 확인하세요.
    - 기본적으로 바로 가기 키는 할당되지 않으며 필요에 따라 직접 지정할 수 있습니다.
    - `verticalTabs.previousAcrossGroups`와 `verticalTabs.nextAcrossGroups`는 그룹을 넘어 이전 및 다음 탭으로 전환합니다. <mark>이 두 명령은 매우 자주 사용되므로 VS Code의 기본 바로 가기를 덮어쓰고 `Ctrl+Tab`과 `Ctrl+Shift+Tab`에 할당하는 것을 권장합니다.</mark>
- 여러 설정 항목을 추가했습니다. 자세한 내용은 각 설정 설명을 확인하세요.

### VS Code 기본 컨텍스트 메뉴 통합

- 이제 탭 컨텍스트 메뉴에 VS Code 자체와 다른 확장이 기본 편집기 탭 메뉴에 등록한 작업을 표시할 수 있습니다.
- VS Code 기본 컨텍스트 메뉴의 사용 여부를 제어하는 `verticalTabs.showNativeContextMenuActions` 설정을 추가했습니다. 기본값은 사용입니다.
- 키보드로 기본 하위 메뉴에 진입하고 조작할 수 있습니다.

### 탭 검색 및 위치 찾기

- 탭 이름으로 필터링할 수 있는 실시간 탭 검색을 추가했습니다.
- 작업 영역 상대 경로 검색을 선택적으로 사용하고 결과에서 일치하는 경로를 표시하고 강조할 수 있습니다.
- 정규식 검색을 지원합니다. 잘못된 정규식은 오류를 표시하지만 현재 목록을 손상시키지 않습니다.
- 일치하는 탭 수와 그룹 수를 표시하고 일치한 텍스트를 강조합니다.
- 검색 중에는 결과가 포함된 그룹을 자동으로 펼치고 검색을 지우면 기존 접힘 상태를 복원합니다.

### 경로 표시 및 같은 이름의 파일 구분

`verticalTabs.relativePathDisplay` 설정은 최종적으로 다음 다섯 가지 모드를 제공합니다.

- 경로를 표시하지 않습니다.
- 이름이 같은 파일에만 상위 디렉터리 이름을 표시합니다.
- 이름이 같은 파일에만 작업 영역 상대 경로를 표시합니다.
- 모든 파일에 항상 상위 디렉터리 이름을 표시합니다.
- 모든 파일에 항상 작업 영역 상대 경로를 표시합니다.

경로는 탭 이름 아래에 표시됩니다. 작업 영역 루트의 파일과 작업 영역 밖의 파일에는 식별 가능한 상위 디렉터리 정보를 추가로 사용합니다.

### 탭 탐색, 정렬 및 이동

- 탭이 마지막으로 성공적으로 활성화된 시간을 기준으로 전체 탭을 MRU 순서로 정렬하는 '최근 사용' 모드를 추가했습니다.
- 새로 열고 활성화한 탭은 가장 최근에 사용한 항목이 되며, 아직 활성화하지 않은 탭은 안정적인 순서를 유지합니다.
- '항상 활성 탭 따라가기' 설정을 추가했습니다. 편집기를 전환하면 해당 그룹을 자동으로 펼치고 활성 탭을 보이는 영역으로 스크롤합니다.
- 설정 가능한 명령 여덟 개를 추가했습니다.
    - 그룹 안에서 이전 또는 다음 탭으로 전환합니다.
    - 그룹을 넘어 이전 또는 다음 탭으로 전환합니다.
    - 현재 그룹 안에서 탭을 위 또는 아래로 이동합니다.
    - 이전 또는 다음 그룹으로 이동합니다.
- 이동 명령은 다중 선택을 지원하며 선택한 탭 사이의 상대적 순서를 유지합니다.
- 수동 정렬은 그룹 안에서의 이동을 지원합니다. 디렉터리 그룹에서는 파일을 다른 그룹으로 이동할 수 있고, 파일 형식 그룹에서는 규칙에 맞지 않는 그룹 간 이동을 제한합니다.

### 작업 세트 및 세션 복원

- 작업 영역 범위의 '작업 세트'를 추가하여 다음 항목을 저장할 수 있습니다.
    - 현재 열려 있는 탭.
    - 기본 편집기 그룹과 탭 순서.
    - 활성 탭.
    - 수동 그룹과 수동 정렬.
    - 탭과 탭 그룹의 고정 상태.
    - 그룹의 접힘 상태.
    - 현재 그룹화 모드와 정렬 모드.
- 명령 팔레트 또는 세로 탭 표시줄에서 작업 세트를 만들고, 불러오고, 덮어쓰고, 이름을 바꾸고, 삭제할 수 있습니다.
- 불러오기 전에 닫힐 수 있는 탭과 저장하지 않은 탭을 나열합니다. 저장하지 않은 탭과 고정된 탭은 기본적으로 보호됩니다.
- 원래 경로가 없으면 작업 영역에 같은 이름의 파일이 정확히 하나만 있을 때 자동으로 연결하여 잘못된 복원을 방지합니다.

### 탭 상태 표시

- 참고: 이 기능은 아직 모두 테스트되지 않았습니다.
- 파일 시스템 읽기 전용, 권한에 따른 읽기 전용, VS Code 읽기 전용 규칙을 포함하는 리소스 읽기 전용 상태를 추가했습니다.
- 리소스 없음, 접근 권한 없음, 파일 시스템 사용 불가 상태를 추가했습니다.
- 파일 삭제 또는 복원, 권한이나 읽기 전용 설정 변경 후 상태를 새로 고칩니다.
- 탭 오른쪽에 미리 보기, 고정, 읽기 전용, 저장하지 않음, 리소스 오류, 이동 불가 상태를 일관된 순서로 표시합니다.
- 저장하지 않음 상태는 닫기 버튼 근처에 모아 표시합니다.
- 탭 텍스트에 더 넓은 공간을 제공합니다. 닫기 버튼은 마우스를 올리거나 키보드 포커스가 탭 안으로 들어올 때만 표시됩니다.

### 레이아웃, 위치 및 시작 진입점

- `verticalTabs.position`을 추가하여 세로 탭 표시줄을 편집기 영역의 왼쪽 또는 오른쪽에 놓고 즉시 전환할 수 있습니다.
- `verticalTabs.toolbarPosition`을 추가하여 도구 영역을 탭 목록 위나 아래에 고정할 수 있습니다.
- 상태 표시줄 오른쪽에 항상 표시되는 표시/숨기기 버튼을 추가했습니다. 아이콘은 탭 표시줄의 위치와 표시 상태에 따라 달라집니다.
- 최종 인터페이스에는 VS Code 테마 색상과 Codicon 작업 버튼을 사용합니다.

### 키보드 및 접근성

- 포커스가 세로 탭의 빈 영역에 있을 때 방향키, `Home`, `End`, `Enter`로 탭을 탐색하고 활성화할 수 있습니다.
    - 실용성은 높지 않습니다. 키보드로 탭을 이동하거나 활성화하면 포커스가 탭 내부로 들어가 이후에는 세로 탭 안에서 계속 이동할 수 없습니다.
- 탭 및 그룹 메뉴는 메뉴 키, `Shift+F10`, 방향키, `Enter`, Space, `Esc`를 지원합니다.
