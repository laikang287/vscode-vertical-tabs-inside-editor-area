## [1.0.0] - 2026-07-23

<mark>Это крупное обновление версии. Из-за большого количества изменений при возникновении ошибок можно рассмотреть возврат к версии 0.2.1.</mark>

### Основные возможности

- <mark>Контекстное меню вертикальных вкладок может отображать все кнопки, доступные на горизонтальных вкладках VS Code, включая кнопки самого VS Code и сторонних расширений.</mark>
- Стиль интерфейса обновлён, чтобы лучше соответствовать темам VS Code.
- Добавлена возможность сохранять и загружать рабочие наборы.
- Вертикальные вкладки можно размещать слева или справа.
- Улучшена функция поиска.
- Добавлен параметр `verticalTabs.relativePathDisplay`, управляющий условиями отображения пути во вкладке. Например, можно показывать родительский каталог только для файлов с одинаковыми именами.
- Добавлено несколько настраиваемых сочетаний клавиш для переключения и перемещения вкладок и других операций.
    - Подробности приведены в описаниях сочетаний клавиш.
    - По умолчанию сочетания не назначены; при необходимости назначьте их самостоятельно.
    - `verticalTabs.previousAcrossGroups` и `verticalTabs.nextAcrossGroups` переключают на предыдущую или следующую вкладку между группами. <mark>Эти две команды используются очень часто. Рекомендуется назначить им `Ctrl+Tab` и `Ctrl+Shift+Tab`, переопределив стандартные сочетания VS Code.</mark>
- Добавлено несколько параметров; подробности приведены в их описаниях.

### Интеграция с нативным контекстным меню VS Code

- Контекстное меню вкладки теперь может отображать действия, зарегистрированные самим VS Code и другими расширениями в нативном меню вкладок редактора.
- Добавлен параметр `verticalTabs.showNativeContextMenuActions`, управляющий включением нативных действий контекстного меню VS Code. По умолчанию они включены.
- Нативные подменю можно открывать и использовать с клавиатуры.

### Поиск и нахождение вкладок

- Добавлен поиск вкладок в реальном времени с фильтрацией по имени вкладки.
- В поиск можно включить пути относительно рабочей области, а совпавшие пути отображаются и подсвечиваются в результатах.
- Поддерживается поиск по регулярным выражениям. Недопустимое выражение показывает ошибку, не нарушая текущий список.
- Отображается количество совпавших вкладок и групп, а найденный текст подсвечивается.
- Во время поиска группы с результатами автоматически разворачиваются; после очистки поиска восстанавливается их прежнее свёрнутое состояние.

### Отображение путей и различение одноимённых файлов

Параметр `verticalTabs.relativePathDisplay` теперь предоставляет пять режимов:

- Не показывать пути.
- Показывать родительский каталог только для одноимённых файлов.
- Показывать путь относительно рабочей области только для одноимённых файлов.
- Всегда показывать родительский каталог для всех файлов.
- Всегда показывать путь относительно рабочей области для всех файлов.

Путь отображается под именем вкладки. Для файлов в корне рабочей области и за её пределами в качестве дополнительного контекста используется распознаваемая информация о родительском каталоге.

### Навигация, сортировка и перемещение вкладок

- Добавлен режим сортировки «Недавно использованные», который глобально упорядочивает вкладки по принципу MRU на основе времени их последней успешной активации.
- Новые открытые и активированные вкладки становятся недавно использованными; ещё не активированные вкладки сохраняют стабильный порядок.
- Добавлен параметр «Всегда следовать за активной вкладкой»: после переключения редактора соответствующая группа автоматически разворачивается, а активная вкладка прокручивается в видимую область.
- Добавлено восемь настраиваемых команд:
    - Перейти к предыдущей или следующей вкладке внутри группы.
    - Перейти к предыдущей или следующей вкладке между группами.
    - Переместить вкладку вверх или вниз внутри текущей группы.
    - Переместить вкладку в предыдущую или следующую группу.
- Команды перемещения поддерживают множественный выбор и сохраняют относительный порядок выбранных вкладок.
- Ручная сортировка позволяет перемещать вкладки внутри группы. Группировка по каталогам позволяет перемещать файлы между группами, а группировка по типу файла запрещает перемещения, не соответствующие правилу группировки.

### Рабочие наборы и восстановление сеанса

- Добавлены рабочие наборы уровня рабочей области, которые могут сохранять:
    - Текущие открытые вкладки.
    - Нативные группы редакторов и порядок вкладок.
    - Активную вкладку.
    - Ручные группы и ручную сортировку.
    - Закреплённое состояние вкладок и групп вкладок.
    - Свёрнутое состояние групп.
    - Текущие режимы группировки и сортировки.
- Рабочие наборы можно создавать, загружать, перезаписывать, переименовывать и удалять из палитры команд или вертикальной панели вкладок.
- Перед загрузкой расширение перечисляет вкладки, которые могут быть закрыты, и несохранённые вкладки. Несохранённые и закреплённые вкладки защищены по умолчанию.
- Если исходный путь отсутствует, расширение автоматически связывает его только тогда, когда в рабочей области имеется ровно один одноимённый файл, что предотвращает ошибочное восстановление.

### Отображение состояния вкладок

- Примечание: эта часть ещё не полностью протестирована.
- Добавлены состояния ресурса «только для чтения», включая файловую систему только для чтения, ограничения разрешений и правила VS Code для режима только для чтения.
- Добавлены состояния для отсутствующих ресурсов, недостаточных прав доступа и недоступных файловых систем.
- Состояние обновляется после удаления или восстановления файлов, а также при изменении разрешений или параметров только для чтения.
- Справа во вкладке единообразно отображаются состояния предварительного просмотра, закрепления, только для чтения, отсутствия сохранения, ошибки ресурса и недоступной навигации.
- Состояние несохранённости отображается рядом с кнопкой закрытия.
- Для текста вкладки доступно больше ширины. Кнопка закрытия появляется только при наведении указателя или попадании клавиатурного фокуса во вкладку.

### Макет, расположение и точки входа

- Добавлен `verticalTabs.position`, позволяющий размещать вертикальную панель вкладок слева или справа в области редактора и немедленно применять изменение.
- Добавлен `verticalTabs.toolbarPosition`, позволяющий закрепить область инструментов над списком вкладок или под ним.
- Справа в строке состояния добавлена постоянно доступная кнопка показа/скрытия. Её значок меняется в зависимости от положения и видимости панели вкладок.
- В итоговом интерфейсе используются цвета темы VS Code и кнопки действий Codicon.

### Клавиатура и специальные возможности

- Когда фокус находится в пустой области вертикальных вкладок, для навигации и активации вкладок можно использовать клавиши со стрелками, `Home`, `End` и `Enter`.
    - Практическая полезность ограничена: после перемещения или активации вкладки с клавиатуры фокус переходит внутрь неё, поэтому дальнейшая навигация по вертикальным вкладкам становится недоступна.
- Меню вкладок и групп поддерживают клавишу меню, `Shift+F10`, клавиши со стрелками, `Enter`, пробел и `Esc`.
