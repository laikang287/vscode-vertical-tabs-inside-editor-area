## [1.0.0] - 2026-07-23

<mark>版本重大更新。由於更新內容很多，如遇到錯誤，可考慮退回 0.2.1 版本。</mark>

### 重點功能說明

- <mark>垂直標籤頁中的右鍵選單可顯示 VS Code 橫向標籤頁中的所有按鈕，包括官方和第三方擴充的按鈕。</mark>
- 更新介面樣式，使其更貼近 VS Code 主題風格。
- 可儲存、載入工作集。
- 垂直標籤頁可切換至左側或右側。
- 強化搜尋功能。
- 新增 `verticalTabs.relativePathDisplay` 設定，可設定標籤在何種情況下顯示路徑，例如僅讓同名檔案顯示所在目錄名稱。
- 新增多個可設定的快速鍵，支援標籤頁切換、移動等操作。
    - 詳細內容可自行查看快速鍵說明。
    - 預設不綁定快速鍵，如有需要可自行綁定。
    - `verticalTabs.previousAcrossGroups` 和 `verticalTabs.nextAcrossGroups` 可跨分組切換至上一個和下一個標籤。<mark>這兩個快速鍵非常常用，建議綁定為 `Ctrl+Tab` 和 `Ctrl+Shift+Tab`，覆蓋 VS Code 的預設快速鍵。</mark>
- 新增多個設定項目，詳細內容請自行查看。

### VS Code 原生右鍵選單整合

- 標籤右鍵選單現在可以顯示 VS Code 本身及其他擴充註冊到原生編輯器標籤選單的操作。
- 新增 `verticalTabs.showNativeContextMenuActions` 開關，用於控制是否啟用 VS Code 原生右鍵選單，預設啟用。
- 支援透過鍵盤進入和操作原生子選單。

### 標籤搜尋與定位

- 新增即時標籤搜尋，可依標籤名稱篩選。
- 可選擇搜尋工作區相對路徑，並在結果中顯示及醒目提示相符路徑。
- 支援正規表示式搜尋；無效的正規表示式會顯示錯誤，但不會破壞目前列表。
- 顯示相符標籤數與相符分組數，並醒目提示命中文字。
- 搜尋時自動展開包含結果的分組；清除搜尋後恢復原有折疊狀態。

### 路徑顯示與同名檔案消歧

新增 `verticalTabs.relativePathDisplay` 設定，最終提供五種模式：

- 不顯示路徑。
- 僅讓同名檔案顯示所在目錄名稱。
- 僅讓同名檔案顯示工作區相對路徑。
- 所有檔案一律顯示目錄名稱。
- 所有檔案一律顯示工作區相對路徑。

路徑顯示在標籤名稱下方；工作區根目錄檔案和工作區外檔案會使用可辨識的父目錄資訊作為補充。

### 標籤導覽、排序與移動

- 新增「最近使用」排序模式，依標籤最後一次成功啟用的時間進行全域 MRU 排序。
- 新開啟並啟用的標籤會成為最近使用項目；尚未啟用的標籤會保持穩定順序。
- 新增「一律跟隨作用中標籤」設定：切換編輯器後自動展開對應分組，並將作用中標籤捲動至可見區域。
- 新增八個可設定命令：
    - 分組內上一個、下一個標籤。
    - 跨分組上一個、下一個標籤。
    - 在目前分組內向上、向下移動標籤。
    - 移動到上一個、下一個分組。
- 移動命令支援多選，並保留所選標籤之間的相對順序。
- 手動排序支援分組內移動；目錄分組支援跨組移動檔案，檔案類型分組會限制不成立的跨組移動。

### 工作集與工作階段還原

- 新增工作區層級的「工作集」，可以儲存：
    - 目前開啟的標籤。
    - 原生編輯器群組及標籤順序。
    - 作用中標籤。
    - 手動分組及手動排序。
    - 標籤和標籤群組的固定狀態。
    - 分組折疊狀態。
    - 目前的分組模式和排序模式。
- 可從命令選擇區或垂直標籤列建立、載入、覆寫、重新命名和刪除工作集。
- 載入前會列出可能關閉的標籤及未儲存標籤，預設保護未儲存標籤和固定標籤。
- 原始路徑遺失時，只有工作區中存在唯一同名檔案才會自動關聯，以避免錯誤還原。

### 標籤狀態顯示

- 註：這部分功能尚未全部測試。
- 新增資源唯讀狀態，包括檔案系統唯讀、權限唯讀以及 VS Code 唯讀規則。
- 新增資源不存在、無存取權限和檔案系統無法使用的狀態。
- 檔案刪除、還原、權限或唯讀設定變更後會重新整理狀態。
- 標籤右側統一顯示預覽、固定、唯讀、未儲存、資源異常及無法跳轉狀態。
- 未儲存狀態集中顯示在關閉按鈕附近。
- 標籤文字區域獲得更多可用寬度；關閉按鈕只會在懸停或鍵盤焦點進入時顯示。

### 版面配置、位置與啟動入口

- 新增 `verticalTabs.position`，可將垂直標籤列放在編輯器區域左側或右側，並立即切換。
- 新增 `verticalTabs.toolbarPosition`，可將工具區固定在標籤列表上方或下方。
- 狀態列右側新增常駐的顯示/隱藏按鈕；圖示會依標籤列位置和顯示狀態變化。
- 最終介面採用 VS Code 主題色和 Codicon 操作按鈕。

### 鍵盤與無障礙操作

- 當焦點位於垂直標籤頁空白位置時，可使用方向鍵、`Home`、`End` 和 `Enter` 瀏覽及啟用標籤。
    - 實用性不高，因為使用鍵盤按鍵移動、啟用標籤頁後，焦點會進入標籤頁內部，之後便無法繼續在垂直標籤頁中移動。
- 標籤和分組選單支援選單鍵、`Shift+F10`、方向鍵、`Enter`、空白鍵及 `Esc`。
