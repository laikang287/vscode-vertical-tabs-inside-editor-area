## [1.0.0] - 2026-07-23

<mark>大規模なバージョンアップです。変更点が非常に多いため、不具合が発生した場合はバージョン 0.2.1 に戻すことをご検討ください。</mark>

### 主な機能

- <mark>垂直タブのコンテキストメニューに、VS Code の横タブにあるすべてのボタンを表示できるようになりました。VS Code 標準およびサードパーティー拡張機能のボタンも含まれます。</mark>
- インターフェイスのスタイルを更新し、VS Code のテーマに近づけました。
- ワークセットの保存と読み込みに対応しました。
- 垂直タブを左側または右側に切り替えられるようになりました。
- 検索機能を強化しました。
- `verticalTabs.relativePathDisplay` 設定を追加しました。同名ファイルにのみ親ディレクトリ名を表示するなど、タブにパスを表示する条件を設定できます。
- タブの切り替えや移動などに使用できる、複数の設定可能なショートカットを追加しました。
    - 詳細はキーボードショートカットの説明をご確認ください。
    - 初期状態ではショートカットは割り当てられていません。必要に応じて設定してください。
    - `verticalTabs.previousAcrossGroups` と `verticalTabs.nextAcrossGroups` は、グループをまたいで前後のタブに切り替えます。<mark>この 2 つは非常によく使うコマンドです。VS Code の既定のショートカットを上書きして、`Ctrl+Tab` と `Ctrl+Shift+Tab` に割り当てることをお勧めします。</mark>
- 複数の設定項目を追加しました。詳細は各設定の説明をご確認ください。

### VS Code ネイティブコンテキストメニューとの統合

- タブのコンテキストメニューに、VS Code 自体および他の拡張機能がネイティブのエディタタブメニューへ登録した操作を表示できるようになりました。
- VS Code ネイティブのコンテキストメニューを有効にするかどうかを制御する `verticalTabs.showNativeContextMenuActions` を追加しました。既定では有効です。
- キーボードでネイティブのサブメニューを開いて操作できます。

### タブの検索と位置特定

- タブ名で絞り込めるリアルタイム検索を追加しました。
- ワークスペース相対パスを検索対象に含め、一致したパスを結果に表示して強調できます。
- 正規表現検索に対応しました。無効な正規表現ではエラーを表示しますが、現在の一覧は崩れません。
- 一致するタブ数とグループ数を表示し、一致した文字列を強調します。
- 検索中は結果を含むグループを自動的に展開し、検索をクリアすると元の折りたたみ状態に戻します。

### パス表示と同名ファイルの識別

`verticalTabs.relativePathDisplay` 設定では、最終的に次の 5 つのモードを利用できます。

- パスを表示しない。
- 同名ファイルにのみ親ディレクトリ名を表示する。
- 同名ファイルにのみワークスペース相対パスを表示する。
- すべてのファイルに常に親ディレクトリ名を表示する。
- すべてのファイルに常にワークスペース相対パスを表示する。

パスはタブ名の下に表示されます。ワークスペース直下のファイルやワークスペース外のファイルには、識別可能な親ディレクトリ情報を補足として使用します。

### タブのナビゲーション、並べ替え、移動

- タブが最後に正常にアクティブ化された時刻に基づいて全体を MRU 順に並べ替える「最近使用した項目」モードを追加しました。
- 新しく開いてアクティブ化したタブは最近使用した項目になり、まだアクティブ化されていないタブは安定した順序を保ちます。
- 「常にアクティブなタブを追従」設定を追加しました。エディタを切り替えると対応するグループを自動的に展開し、アクティブなタブを表示領域までスクロールします。
- 8 個の設定可能なコマンドを追加しました。
    - グループ内の前または次のタブへ移動。
    - グループをまたいで前または次のタブへ移動。
    - 現在のグループ内でタブを上または下へ移動。
    - 前または次のグループへ移動。
- 移動コマンドは複数選択に対応し、選択したタブ間の相対順序を維持します。
- 手動並べ替えではグループ内の移動が可能です。ディレクトリグループではファイルを別のグループへ移動でき、ファイル種類グループでは規則に適合しないグループ間移動を制限します。

### ワークセットとセッションの復元

- ワークスペース単位の「ワークセット」を追加し、次の項目を保存できます。
    - 現在開いているタブ。
    - ネイティブのエディタグループとタブの順序。
    - アクティブなタブ。
    - 手動グループと手動並べ替え。
    - タブおよびタブグループのピン留め状態。
    - グループの折りたたみ状態。
    - 現在のグループ化モードと並べ替えモード。
- コマンドパレットまたは垂直タブバーから、ワークセットの作成、読み込み、上書き、名前変更、削除を行えます。
- 読み込み前に、閉じられる可能性のあるタブと未保存のタブを一覧表示します。未保存のタブとピン留めしたタブは既定で保護されます。
- 元のパスが見つからない場合は、ワークスペース内に同名ファイルが 1 つだけ存在するときに限って自動的に関連付け、誤った復元を防ぎます。

### タブ状態の表示

- 注：この機能はまだすべてテストされていません。
- ファイルシステムの読み取り専用、権限による読み取り専用、VS Code の読み取り専用規則を含む、リソースの読み取り専用状態を追加しました。
- リソースが存在しない、アクセス権限がない、ファイルシステムを利用できない状態を追加しました。
- ファイルの削除や復元、権限または読み取り専用設定の変更後に状態を更新します。
- タブの右側に、プレビュー、ピン留め、読み取り専用、未保存、リソース異常、移動不可の各状態を統一して表示します。
- 未保存状態は閉じるボタン付近にまとめて表示します。
- タブ文字列に利用できる幅を増やしました。閉じるボタンは、マウスを重ねたとき、またはキーボードフォーカスがタブ内に入ったときだけ表示されます。

### レイアウト、位置、起動エントリ

- `verticalTabs.position` を追加し、垂直タブバーをエディタ領域の左側または右側に配置して即時に切り替えられるようにしました。
- `verticalTabs.toolbarPosition` を追加し、ツール領域をタブ一覧の上または下に固定できるようにしました。
- ステータスバーの右側に常時表示される表示/非表示ボタンを追加しました。アイコンはタブバーの位置と表示状態に応じて変化します。
- 最終的なインターフェイスには VS Code のテーマカラーと Codicon の操作ボタンを採用しました。

### キーボードとアクセシビリティ

- 垂直タブの空白部分にフォーカスがあるとき、方向キー、`Home`、`End`、`Enter` でタブを移動してアクティブ化できます。
    - 実用性は高くありません。キーボードでタブを移動またはアクティブ化するとフォーカスがタブ内部へ移るため、その後は垂直タブ内で移動できなくなります。
- タブとグループのメニューは、メニューキー、`Shift+F10`、方向キー、`Enter`、Space、`Esc` に対応しています。
